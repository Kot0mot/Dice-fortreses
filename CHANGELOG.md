# Changelog

All notable changes to this project are documented in this file.

## v0.1.0 - 2026-05-07

- Shipped playable Dice Fortresses MVP for CLI and Web.
- Added deterministic replay/log flow and one-command quality checks (`check`, `smoke`, `demo`).
- Added simulation, challenge mode, and playtest toolkit with telemetry export/aggregation.
- Added release bundling flow with reproducible `release/` output and manifest.
- Finalized release docs for onboarding, handoff, and operational runbook.
